# M3.5 — Cross-reference Graph Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On the complex route only, follow the knowledge-graph edges from the top reranked results to fetch and inject the text of cross-referenced articles as extra numbered context blocks.

**Architecture:** One new orchestrator method `_expand_cross_references` (+ 3 small static/private helpers) fetches referenced-article text via the existing server-side `scroll_article`, deduped/temporal-filtered/capped. It is appended after rerank in both the non-stream (`_complex_pipeline`) and stream (`query_stream`) complex routes. A new deterministic eval mode measures referenced-article recall before vs after expansion on a new multi-hop cohort.

**Tech Stack:** Python 3.13, pytest, Qdrant (`LegalVectorStore`), SQLite metadata store, existing `CitationLookup`.

## Global Constraints

- **Complex route only.** Simple / medium / lookup / out-of-scope routes and all non-complex behavior must be byte-identical (0 behavior change). Verified by the full suite staying green.
- **Never break the route.** `_expand_cross_references` runs under `try/except`; any failure logs and returns `[]`.
- **$0 / CPU budget.** Expansion appends *after* rerank — expanded blocks never enter the rerank pool (M2.6 bench: rerank P95 @pool 50/100 = 2180/7582 ms).
- **Params (verbatim):** `SEED_COUNT = 3`, `HOPS = 1`, `MAX_EXPANDED = 4`, `SCROLL_CAP = 1`.
- **Measure-or-drop.** M3 gate: `refusal_recall ≥ 0.7619`, `false_refusal ≤ 0.0972`, no new OOS leak. If the positive gate fails, M3.5 is dropped-with-writeup.
- **Verify every eval label against the ingested parquet** (`data/processed/corpus_600docs.parquet` / Qdrant) — stale labels have bitten this project twice.
- Run tests with `.venv/bin/python -m pytest`. Full suite: `make test`.

```python
    # ── Cross-reference graph expansion (M3.5) ───────────────────

    def _expand_cross_references(
        self, results: List[SearchResult], is_comparison: bool = False,
    ) -> List[SearchResult]:
        """
        Complex-route only (Plan §3.5): follow knowledge-graph edges from the
        top reranked results and fetch the TEXT of cross-referenced articles,
        so multi-hop questions ("theo quy định tại Điều Y") get Điều Y's
        content in context. Returns the extra blocks to APPEND (never mutates
        `results`); the caller adds them after rerank so they never enter the
        rerank pool (M2.6 CPU-latency cap). Any failure -> [] (never breaks
        the route).
        """
        if not self.cross_ref_expansion:
            return []
        try:
            graph = self.metadata_store.get_graph()
            edges = graph.get("edges", [])
            nodes = graph.get("nodes", [])
            if not edges:
                return []

            adjacency: Dict[str, List[str]] = {}
            for e in edges:
                adjacency.setdefault(e.get("source", ""), []).append(e.get("target", ""))
            node_map = {n["id"]: n for n in nodes}

            existing = {
                (r.document_id, self._article_num(r.article))
                for r in results if r.document_id and r.article
            }

            collected: List[SearchResult] = []
            collected_keys: set = set()
            for seed in results[:CROSS_REF_SEED_COUNT]:
                if not (seed.document_id and seed.article):
                    continue
                node_id = f"doc_{seed.document_id}_{seed.article.lower().replace(' ', '_')}"
                for nid in self._graph_neighbors(node_id, adjacency, CROSS_REF_HOPS):
                    if len(collected) >= CROSS_REF_MAX_EXPANDED:
                        break
                    node = node_map.get(nid)
                    if not node:
                        continue
                    for r in self._fetch_neighbor(node):
                        if len(collected) >= CROSS_REF_MAX_EXPANDED:
                            break
                        if not (r.document_id and r.article):
                            continue
                        key = (r.document_id, self._article_num(r.article))
                        if key in existing or key in collected_keys:
                            continue
                        collected_keys.add(key)
                        collected.append(r)
                if len(collected) >= CROSS_REF_MAX_EXPANDED:
                    break

            if not collected:
                return []
            annotations = self._annotate_phase2(collected)
            collected = self._filter_in_effect(
                collected, annotations, keep_superseded=is_comparison,
            )
            return collected[:CROSS_REF_MAX_EXPANDED]
        except Exception as e:
            print(f"⚠️ Cross-ref expansion failed (skip): {e}")
            return []

    @staticmethod
    def _article_num(article: Optional[str]) -> str:
        """Extract the article number ('Điều 12a' -> '12a') for scroll_article
        + dedup keys. Falls back to the raw string if no digit is present."""
        m = re.search(r'(\d+[a-z]?)', article or "")
        return m.group(1) if m else (article or "")

    @staticmethod
    def _graph_neighbors(
        start: str, adjacency: Dict[str, List[str]], hops: int,
    ) -> List[str]:
        """BFS out-direction from `start`, limited to `hops`. First-seen order."""
        seen = {start}
        frontier = {start}
        out: List[str] = []
        for _ in range(hops):
            nxt: set = set()
            for node in frontier:
                for nb in adjacency.get(node, []):
                    if nb not in seen:
                        seen.add(nb)
                        nxt.add(nb)
                        out.append(nb)
            frontier = nxt
            if not frontier:
                break
        return out

    def _fetch_neighbor(self, node: Dict) -> List[SearchResult]:
        """Fetch the chunk(s) for one graph neighbor node via server-side
        scroll_article. Article nodes fetch directly; external_ref nodes
        resolve the law name to a doc first (skip if ambiguous/not in corpus)."""
        num = self._article_num(node.get("article", ""))
        if not num:
            return []
        if node.get("node_type") == "external_ref":
            law_name = node.get("law_name", "")
            if not law_name:
                return []
            cl = self._get_citation_lookup()
            doc_ids = cl.resolve_doc(law_name, year=None)
            all_ids = list(cl._get_alias_index().keys())
            if not doc_ids or set(doc_ids) == set(all_ids):
                return []  # law not unambiguously in corpus
            return self.vector_store.scroll_article(doc_ids[:1], num, cap=CROSS_REF_SCROLL_CAP)
        doc_id = node.get("doc_id")
        if not doc_id:
            return []
        return self.vector_store.scroll_article([doc_id], num, cap=CROSS_REF_SCROLL_CAP)
```

```python
    def complex_retrieve(
        self, question: str, is_comparison: bool = False,
    ) -> Tuple[List[SearchResult], Optional[List[float]]]:
        """Complex-route retrieval (rewrite → multi-query → HyDE → hybrid →
        dedup → temporal filter → dynamic-top-k → rerank). Returns
        (results, rerank_scores) POST-rerank, PRE-cross-ref-expansion. Shared
        by _complex_pipeline and the M3.5 eval harness so both measure the
        same seed set. NOTE: query_stream keeps its own inline copy because it
        interleaves __STEP__ progress events between these stages."""
        rewritten = self.llm.generate(QUERY_REWRITE_PROMPT.format(question=question), temperature=0.1).strip()
        expanded_raw = self.llm.generate(MULTI_QUERY_PROMPT.format(question=rewritten), temperature=0.3)
        queries = [q.strip() for q in expanded_raw.split("\n") if q.strip() and q[0].isdigit()]
        queries = [q.split(". ", 1)[-1] if ". " in q else q for q in queries]
        hyde_text = self.llm.generate(HYDE_PROMPT.format(question=question), temperature=0.2).strip()

        all_queries = [rewritten] + queries[:2] + [hyde_text]
        all_results = []
        for q in all_queries:
            output = self.embedder.encode([q], return_dense=True, return_sparse=True)
            dense_vec = output["dense_vecs"][0]
            sparse_vec = output["lexical_weights"][0] if output["lexical_weights"] else {}
            results = self.vector_store.search_hybrid(dense_vec.tolist(), sparse_vec, top_k=10,
                                                      exclude_superseded=not is_comparison)
            all_results.extend(results)

        seen = set()
        unique_results = []
        for r in sorted(all_results, key=lambda x: x.score, reverse=True):
            if r.point_id not in seen:
                seen.add(r.point_id)
                unique_results.append(r)
        annotations = self._annotate_phase2(unique_results)
        unique_results = self._filter_in_effect(unique_results, annotations, keep_superseded=is_comparison)
        top_k = self._dynamic_top_k(unique_results, min_k=5, max_k=20)
        results = unique_results[:top_k]
        return self._rerank_results(question, results)
```

```python
    def _complex_pipeline(self, question: str, start_time: float, is_comparison: bool = False) -> RAGResponse:
        """COMPLEX: full pipeline (rewrite → multi-query → HyDE → hybrid → rerank → expand → compress → generate)."""
        results, rerank_scores = self.complex_retrieve(question, is_comparison)

        # M3.5: append cross-referenced article text (after rerank, capped).
        expanded = self._expand_cross_references(results, is_comparison=is_comparison)
        if expanded:
            results = results + expanded

        # Phase 2 annotations for the final (post-expansion) result set.
        annotations = self._annotate_phase2(results)

        # 7. Context Compression — extract only relevant sentences
        results = self._expand_to_parent(results)  # Plan §3.4
        context = self._build_context(results, annotations)
        context = self._compress_context(question, context)

        # 8. Generate
        prompt = GENERATION_PROMPT.format(context=context, question=question)
        raw = self.llm.generate(prompt=prompt, system_prompt=SYSTEM_PROMPT, temperature=0.1, json_mode=False)

        citations = self._build_citations(results, annotations)
        context = self._build_context(results, annotations)

        conf_result, ver_result, final_answer = self._post_process(
            question, raw, results, context, rerank_scores=rerank_scores,
        )

        parsed = self._parse_response(final_answer, citations)
        parsed.latency_ms = (time.time() - start_time) * 1000
        parsed.pipeline_used = "complex"
        parsed = self._enrich_response(parsed, conf_result, ver_result)
        return parsed
```

```python
def multihop_recall_row(
    expected_articles: List[Dict],
    seed_hits: List[Dict],
    expanded_hits: List[Dict],
) -> Dict:
    """M3.5 metric: referenced-article recall BEFORE vs AFTER cross-ref
    expansion, measured on the SAME seed pass so the delta is purely
    expansion. Lenient (article-level) match. k = full result set — we care
    whether the expected article is present ANYWHERE in the final context,
    not its rank."""
    combined = seed_hits + expanded_hits
    return {
        "recall_before": recall_at_k(seed_hits, expected_articles, len(seed_hits) or 1, lenient=True),
        "recall_after": recall_at_k(combined, expected_articles, len(combined) or 1, lenient=True),
        "n_expanded": len(expanded_hits),
    }
```

```python
def run_multihop(questions: List[Dict], pipeline) -> Dict:
    """M3.5: deterministic referenced-article recall before/after cross-ref
    expansion. Runs the REAL complex retrieval (rewrite/HyDE via LLM) once per
    question, then compares expected-article presence in the seed set vs
    seed+expanded. No generation, no confidence scoring."""
    from src.eval.metrics import multihop_recall_row

    eligible = [q for q in questions if q.get("expected_articles")]
    rows = []
    for q in eligible:
        seed_results, _scores = pipeline.complex_retrieve(q["question"])
        expanded = pipeline._expand_cross_references(seed_results)
        seed_hits = [_result_to_dict(r) for r in seed_results]
        expanded_hits = [_result_to_dict(r) for r in expanded]
        row = {"id": q["id"], "legal_sector": q.get("legal_sector"),
               "expected_articles": q["expected_articles"]}
        row.update(multihop_recall_row(q["expected_articles"], seed_hits, expanded_hits))
        rows.append(row)

    n = len(rows) or 1
    return {
        "n_questions": len(rows),
        "mean_recall_before": round(sum(r["recall_before"] for r in rows) / n, 4),
        "mean_recall_after": round(sum(r["recall_after"] for r in rows) / n, 4),
        "mean_n_expanded": round(sum(r["n_expanded"] for r in rows) / n, 4),
        "rows": rows,
    }
```
