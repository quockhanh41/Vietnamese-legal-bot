# M3.6 — Verbatim-span Quotes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each "Chi tiết" bullet carries a verbatim quoted span from its cited block, and a new observability-only verifier stage string-matches every span against its source.

**Architecture:** Add a `strip_blockquotes` helper (context_blocks) used by both the confidence scorer and the verifier so blockquote spans never leak into the calibrated signals. Add verifier "Tier 1.6" (normalize + substring-match) with new observability-only result fields. Change `SYSTEM_PROMPT` last so blockquotes only appear once the strip machinery exists.

**Tech Stack:** Python 3.13, pytest, existing `src/rag/{verifier,confidence,context_blocks}.py` + `src/llm/prompts.py`. No new dependencies.

## Global Constraints

- **Observability-only**: this milestone must NOT change `VerificationResult.passed`, the 6-signal `DEFAULT_WEIGHTS`, or `REFUSAL_THRESHOLD = 0.700`. No 7th confidence signal, no recalibration in Phase 1.
- **Two refusal gates stay intact** (scope gate + confidence gate) — non-negotiable plan principle #1.
- **Calibration invariant**: only the new Tier 1.6 check ever sees blockquote (`>`) lines. Every pre-existing answer-derived computation gets the answer with blockquotes stripped.
- **Diacritics preserved** in normalization — Vietnamese diacritics are semantically load-bearing.
- **Span guard**: a normalized span shorter than **10 characters** never counts as a match.
- Run tests with `.venv/bin/python -m pytest <path> -q` (matches every test module's docstring).
- Reference spec: `docs/superpowers/specs/2026-07-18-m3.6-verbatim-span-quotes-design.md`.

```python
def strip_blockquotes(text: str) -> str:
    """
    Remove Markdown blockquote lines (first non-space char is `>`) from
    `text`, returning the remaining lines joined by `\\n`.

    M3.6: the verbatim-span blockquotes hold verbatim SOURCE text. This helper
    keeps them out of every answer-derived signal that feeds the calibrated
    confidence score (context_overlap, llm_self_eval, NLI claim split,
    grounding), so the calibrated REFUSAL_THRESHOLD is not perturbed by the
    span-carrying answer format. Only the verbatim-span verifier (Tier 1.6)
    sees the raw answer. Idempotent.
    """
    if not text:
        return ""
    return "\n".join(
        line for line in text.split("\n")
        if not _BLOCKQUOTE_LINE.match(line)
    )
```

Then add the two methods (place them in the Tier 1.5 region, after `_groundable_claims`, near line 331):

```python
    @classmethod
    def _normalize_for_match(cls, text: str) -> str:
        """Normalize a span or block for substring matching (M3.6): unify
        dash/quote/ellipsis chars, casefold, collapse whitespace, strip edge
        dots/spaces. Vietnamese diacritics are preserved."""
        if not text:
            return ""
        t = text
        for ch in cls._DASH_CHARS:
            t = t.replace(ch, "-")
        t = t.replace(cls._ELLIPSIS_CHAR, " ")
        for ch in cls._QUOTE_CHARS:
            t = t.replace(ch, " ")
        t = t.casefold()
        t = re.sub(r"\s+", " ", t).strip()
        return t.strip(" .")

    def _parse_bullet_spans(self, answer: str) -> List[Tuple[List[int], Optional[str]]]:
        """Pair each '### 📋 Chi tiết' bullet with the verbatim span in the
        blockquote line(s) immediately below it (M3.6). Returns
        (block_refs, span) per bullet in order; span is None when the bullet
        has no following blockquote. Consecutive '>' lines are joined with a
        single space. Reuses the same section boundaries as
        `_groundable_claims`."""
        if not answer:
            return []
        clean = re.sub(r"#+\s*", "", answer)
        in_chi_tiet = False
        pairs: List[list] = []      # each item: [refs, [span_parts]]
        current: Optional[list] = None

        for raw_line in clean.split("\n"):
            line = raw_line.strip()
            if not line:
                continue
            if self._CHI_TIET_HEADER.match(line):
                in_chi_tiet = True
                current = None
                continue
            if self._TRA_LOI_NGAN_HEADER.match(line):
                in_chi_tiet = False
                current = None
                continue
            if self._CAU_HOI_HEADER.match(line):
                break
            if not in_chi_tiet:
                continue

            if line.startswith(">"):
                if current is not None:
                    span_text = line.lstrip(">").strip()
                    if span_text:
                        current[1].append(span_text)
                continue

            bullet_match = re.match(r"^[\-\*\•]\s+(.*)", line)
            num_match = None if bullet_match else re.match(r"^\d+[\.\)]\s+(.*)", line)
            if bullet_match or num_match:
                item_text = (bullet_match or num_match).group(1).strip()
                if self._LABEL_ONLY_LINE.match(item_text):
                    current = None      # bare "**Label**:" — no span target
                    continue
                refs = [int(n) for n in self.BLOCK_REF_PATTERN.findall(item_text)]
                current = [refs, []]
                pairs.append(current)

        return [
            (refs, " ".join(parts) if parts else None)
            for refs, parts in pairs
        ]
```

```python
    def _verify_verbatim_spans(self, answer: str, context: str, result: VerificationResult):
        """
        Tier 1.6 (M3.6): string-match each "Chi tiết" bullet's verbatim span
        against the block(s) it cites. A span matches iff its normalized form
        is a substring of a cited block's normalized text (and is at least
        MIN_SPAN_CHARS long). Records a ratio + the unmatched spans (the
        hallucinated-quote evidence) + a count of bullets with no span.

        OBSERVABILITY-ONLY — this method NEVER touches `result.passed`,
        `has_contradiction`, or any confidence signal. It takes the RAW answer
        (the only check that sees blockquotes; every other check receives the
        stripped answer from `verify()`).
        """
        blocks = self._parse_context_blocks(context)
        pairs = self._parse_bullet_spans(answer)

        spans: List[str] = []
        flags: List[bool] = []
        unmatched: List[str] = []
        missing = 0

        for refs, span in pairs:
            if span is None:
                missing += 1
                continue
            spans.append(span)
            norm_span = self._normalize_for_match(span)
            matched = False
            if len(norm_span) >= self.MIN_SPAN_CHARS:
                for n in refs:
                    if n in blocks and norm_span in self._normalize_for_match(blocks[n]):
                        matched = True
                        break
            flags.append(matched)
            if not matched:
                unmatched.append(span)

        result.verbatim_spans = spans
        result.verbatim_match_flags = flags
        result.unverbatim_spans = unmatched
        result.bullets_missing_span = missing
        result.verbatim_match_ratio = (sum(flags) / len(flags)) if flags else 0.0
```
