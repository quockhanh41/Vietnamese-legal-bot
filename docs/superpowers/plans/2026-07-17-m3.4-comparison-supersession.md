# M3.4 Comparison-aware Supersession Relaxation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let comparison questions ("Luật X 2013 vs 2024") retrieve BOTH law versions by relaxing the supersession filter only when the query is a comparison, so the old (superseded) version is no longer dropped.

**Architecture:** Add a `COMPARE: YES/NO` field to the existing single classifier LLM call; thread the resulting `is_comparison` bool from `query()`/`query_stream()` into the simple/medium/complex pipelines; when set, pass `exclude_superseded=False` to the vector search AND `keep_superseded=True` to the `_filter_in_effect` post-filter (both layers must relax together). Non-comparison queries are byte-for-byte unchanged.

**Tech Stack:** Python 3.13, pytest, existing `AdaptiveRAGPipeline` (`src/rag/orchestrator.py`), `COMPLEXITY_CLASSIFIER_PROMPT` (`src/llm/prompts.py`), Qdrant hybrid search, LiteLLM gateway. Production eval stack: mixed AITeamVN embedder + `AITeamVN/Vietnamese_Reranker` + collection `luat_law_ctx_v4_aiteamvn`.

## Global Constraints

- **Fail-safe default:** any classifier parse failure ⇒ `is_comparison=False` (never broaden the pool on a hiccup).
- **No behavior change for non-comparison queries:** `exclude_superseded` stays `True` and `_filter_in_effect` stays active unless `is_comparison` is `True`.
- **`_filter_in_effect` new param default is `keep_superseded=False`** = current behavior.
- **Stream and non-stream must not diverge:** thread the flag through both `query()` and `query_stream()`.
- **Regression gate B0 (must hold):** OOS `refusal_recall ≥ 0.7619`, `false_refusal ≤ 0.0972`, no new OOS leak; non-comparison recall unchanged. Threshold currently `0.700`.
- **Commit only when the user asks** (project rule) — each task lists a commit step; hold the actual `git commit` until the user authorizes, or batch at the end per their preference.
- **Verify before claiming done:** run the shown pytest command and confirm output before checking a step.

```python
    @staticmethod
    def _filter_in_effect(
        results: List[SearchResult], annotations: Dict[str, Dict],
        keep_superseded: bool = False,
    ) -> List[SearchResult]:
        """
        Default temporal filter (Plan §3.6): drop chunks whose source law is
        known to no longer be in effect. Fail-open — a chunk with no Phase 2
        metadata, or is_in_effect=None (unknown), is KEPT. Only an explicit
        is_in_effect=False (a law we positively know was superseded) excludes.

        keep_superseded=True bypasses the drop entirely: comparison queries
        ("Luật X cũ vs Luật X mới") need the superseded old-law version in the
        pool, so the caller opts out of temporal filtering for that query only.
        """
        if keep_superseded:
            return results
        return [
            r for r in results
            if annotations.get(r.point_id, {}).get("is_in_effect") is not False
        ]
```
