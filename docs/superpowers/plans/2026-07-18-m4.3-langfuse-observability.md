# M4.3 Langfuse Observability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One Langfuse trace per chat query with nested spans for route, retrieval, rerank, cross-ref expansion, generation (model/tokens/cost, incl. failed fallback attempts), and verify — a strict no-op when keys are absent.

**Architecture:** A single env-gated module `src/observability.py` re-exports Langfuse v3's `@observe` decorator (or an identity no-op) and registers LiteLLM's `langfuse_otel` callback. Stage methods in the orchestrator and vector store get one decorator line each; generations auto-nest via the shared OpenTelemetry context, so `src/llm/gateway.py` is untouched.

**Tech Stack:** langfuse (v3, OTel-based), litellm `langfuse_otel` callback, pytest, FastAPI/uvicorn for live verify.

**Spec:** `docs/superpowers/specs/2026-07-18-m4.3-langfuse-observability-design.md` (read it first; §7 records review decisions).

## Global Constraints

- Tracing must NEVER break or slow the pipeline: no behavior change when disabled; SDK failures only warn.
- Disabled mode = identity decorator; `langfuse` never imported; litellm callbacks untouched.
- Gate: `TRACING_ENABLED = keys present AND os.getenv("LANGFUSE_TRACING_ENABLED", "true").lower() != "false"` (official SDK kill-switch; never overload `LANGFUSE_TRACING_ENVIRONMENT` — that var only tags).
- No network in CI/tests. `tests/conftest.py` must force the kill-switch (module level, before src imports) because `src/api/main.py:13` runs `load_dotenv()` at import and would leak real keys into the test session.
- Do NOT modify `src/llm/gateway.py`, `NaiveRAGPipeline`, or add a global logging config.
- All existing tests stay green (`pytest tests/ -q`, 421 pre-existing).
- Env var names exactly: `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, `LANGFUSE_HOST`, `LANGFUSE_TRACING_ENABLED`.
- $0 budget: Langfuse Cloud Hobby free tier; live verify uses 1-2 LLM queries only (Groq TPD may be exhausted 2026-07-18 — wait for daily reset if the whole fallback chain 429s).

```python
"""Env-gated Langfuse tracing (M4.3).

Single import point for observability. When LANGFUSE keys are present and the
official kill-switch (LANGFUSE_TRACING_ENABLED=false) is not set, re-exports
the real langfuse @observe decorator and registers LiteLLM's langfuse_otel
callback (OTel-based integration recommended for SDK v3 — generations
auto-nest under the active @observe span via the shared OpenTelemetry
context, including failed 429/fallback attempts). Otherwise @observe is a
zero-overhead identity decorator and langfuse is never imported.

Related env vars (documented, not read here): LANGFUSE_HOST,
LANGFUSE_TRACING_ENVIRONMENT (tagging only — never a kill-switch).
"""

import os


def _tracing_enabled() -> bool:
    if os.getenv("LANGFUSE_TRACING_ENABLED", "true").strip().lower() == "false":
        return False
    return bool(os.getenv("LANGFUSE_PUBLIC_KEY") and os.getenv("LANGFUSE_SECRET_KEY"))


TRACING_ENABLED = _tracing_enabled()

if TRACING_ENABLED:
    import litellm
    from langfuse import observe  # noqa: F401  (re-export)

    if "langfuse_otel" not in litellm.callbacks:
        litellm.callbacks.append("langfuse_otel")
else:
    def observe(*args, **kwargs):
        """Identity no-op decorator: supports @observe and @observe(...)."""
        if len(args) == 1 and callable(args[0]) and not kwargs:
            return args[0]

        def _identity(fn):
            return fn

        return _identity
```
